## Current release scope — 4.0 (breaking change, 2026-11-26)

Decision: remove native HTTP/3 and QUIC entirely from Runwire, rather than expanding or replacing php-quic. Keep PHP 8.4–8.6 support, native HTTP/1.1 and HTTP/2 (client/server), HPACK, WebSocket, gRPC over H2, generic TCP/UDP, TLS/mTLS, event loops, coroutine/process/worker functionality and all existing security and lifecycle fixes. HTTP/3 can terminate at an independent edge proxy; no implicit H3 downgrade, WebTransport implementation, alternate QUIC extension, FFI, or new native dependencies. This is a breaking 4.0 candidate, not 3.1.1. No release, automatic merge or dependency revision pin authorized. The prior 3.1.1 scope and evidence below are historical; retained functionality must be requalified on final 4.0 head. Intentional removals must be explicitly enumerated in API comparison, not globally ignored.
